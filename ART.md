# Иллюстрации CASEFILE

Для первого дела созданы 39 растровых иллюстраций WebP и три самостоятельных векторных элемента. Варианты плотности Android и размеры иконок PWA считаются вариантами одного рисунка. Все фотографические сцены и предметы созданы генерацией изображений специально для этой игры. Текст документов набран в интерфейсе и хранится отдельно. Имена файлов ниже относятся к `public/art`.

| Назначение | Иллюстрации и файлы |
| --- | --- |
| Обложка | Папка с фотографиями особняка и Орлова — `cover` |
| Кабинет и бюро | Стол детектива — `office`, допросная — `interview`, доска — `board`, картотека — `drawers` |
| Шесть исследуемых мест | Кабинет Орлова — `study`, коридор — `hall`, гостиная — `parlor`, автостанция — `street`, архив пристани — `records`, банк — `bank` |
| Шесть портретов | Виктор Орлов — `orlov`, Раиса Ланская — `raisa`, Сергей Веденин — `sergey`, Нина Орлова — `nina`, Пётр Зорин — `petr`, Лидия Белова — `lida` |
| Предметы в доме | Письмо — `letter`, диктофон — `recorder`, батарея — `radiator`, дверной запор — `latch`, часы — `clock`, плащ — `coat`, семейная фотография — `family`, телефон — `telephone` |
| Личные и архивные материалы | Билет — `ticket`, лента возврата — `receipt`, ведомость — `ledger`, конверт — `envelope`, платёжное поручение — `payment`, печать — `stamp`, кассета — `cassette`, экипаж — `crew` |
| Повторный осмотр и документы | Пакет эксперта — `report`, синяя копирка — `torn`, карточка вызова — `dispatch`, пай — `equity`, личные расписки — `signatures`, схема обзора — `plan` |
| Фирменная графика | Словесный знак — `public/logo.svg`, папка-иконка — `public/mark.svg`, стартовая композиция — `public/splash.svg` |

Растровая серия подготовлена из одной обложки и пяти оригинальных фотолистов. Скрипт `tools/art_import.py` выполняет раскрой и WebP-сжатие. Щелчки и дождь синтезируются Web Audio API.
