# CASEFILE — Архив нераскрытых дел

Русскоязычная детективная игра для Android и браузера. Дело № 001 «Последний свидетель» происходит в Реченске в ноябре 1998 года. В кабинете с запертой дверью погиб Виктор Орлов. Игрок ведёт осмотр, допрашивает пятерых собеседников, выстраивает хронологию и сам решает, когда подавать заключение.

[Играть в PWA](https://casefile-rechensk.vercel.app/) · [Скачать debug APK 1.0.0](https://github.com/elcin31/caselife/releases/download/v1.0.0/CASEFILE-1.0.0-debug.apk) · [Сборки GitHub Actions](https://github.com/elcin31/caselife/actions/workflows/build.yml)

## Установка

**PWA.** Откройте игру онлайн. В настройках дождитесь сообщения, что офлайн-материалы сохранены. Нажмите «Установить игру» или выберите установку в меню Chrome. На iPhone используйте «Поделиться» → «На экран Домой» в Safari.

**Android.** Скачайте APK из выпуска, откройте его и при запросе разрешите установку этому браузеру или файловому менеджеру. Это тестовая сборка с отладочной подписью. Все игровые материалы включены. Для установки через ADB выполните `adb install CASEFILE-1.0.0-debug.apk`.

## Как вести дело

Начните с протокола и рабочего кабинета. На локациях доступны метки и подписанный список предметов. Раскройте вложение или осмотрите оборот, затем приобщите находку. Запрашивать повторную беседу можно в телефонной книге. Темы с названиями документов предъявляют найденное свидетельство собеседнику.

На доске закрепляйте улики, людей, реплики и собственные гипотезы. Соединить карточки можно двумя касаниями или двумя списками и кнопкой. Для перемещения доступны перетаскивание и стрелки. Обоснованные сопоставления фиксируются в журнале. В хронологии указывайте порядок, источник и уверенность. В финале выберите человека, мотив, способ и выводы. Можно отложить заключение и продолжить поиск после любой ошибки.

## Локальная разработка

Нужны Node.js 22 и npm. Для Android нужны JDK 21 и Android SDK с платформой 35.

```sh
npm ci
npm run dev
npm test
npm run build
```

Production PWA находится в `dist/`. Для проверки офлайна запустите `python -m http.server 4173 --directory dist`. Для публикации в Vercel импортируйте только `elcin31/caselife`, выберите Vite, команду `npm run build` и каталог `dist`. Ресурсы и Worker используют относительные пути.

```sh
npm run android
cd android
./gradlew assembleDebug
```

APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. Workflow **CASEFILE Android and PWA** собирает APK и PWA при каждом push в main. Workflow **Android device checks** запускает проверку WebView на эмуляторах API 31 и 35 при выпуске тега или вручную.

## Архитектура

| Раздел | Содержимое |
| --- | --- |
| `src/content` | Типы, места, описания, текст документов, досье, темы, зависимости, выводы и правила заключения |
| `src/engine` | Проверка доступа, сбор улик, беседы, граф связей, хронология, финал и сохранения |
| `src/ui` | Отдельные модули кабинета, осмотра, допросов, доски, журнала, установки и синтеза звука |
| `src/main.ts` | Маршрутизация, действия интерфейса и интеграция системной кнопки Android |
| `public/art` | Оригинальные оптимизированные игровые фотографии |
| `tools/offline.mjs` | Построение кеша по содержимому готового релиза |
| `editorial` | Зашифрованная авторская схема, вне веб-сборки и APK |

Интерфейс написан на строгом TypeScript и DOM API. Игровой движок работает отдельно от представления. Состояние невелико и хранится синхронно в localStorage с версией формата и резервной копией. Такой выбор позволяет завершать запись при сворачивании. Сохранения PWA, APK и разных браузеров раздельные. Очистка данных приложения удаляет прогресс.

## Проверка

`npm test` запускает десять проверок правил, достижимости, графа, финалов и сохранений. Для сквозного сценария установите Python Playwright и Chromium, запустите сервер production-сборки и выполните:

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/browser.py
```

При установленном системном Chromium укажите `CASEFILE_CHROMIUM=/usr/bin/chromium`. Тест проходит все 19 улик и четыре исхода, перезагружает сохранения, проверяет 14 экранов на семи ширинах и открывает улику офлайн. Тесты и редакторские материалы не входят в сборку. Правила оценки работают на устройстве и технически доступны при анализе клиентского кода.
